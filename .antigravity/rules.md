# Project Governance & Git Workflow Rules

## Granular Atomic Micro-Commits
- **Always commit frequently with maximum granular micro-commits.**
- Every function, UI component adjustment, schema update, asset addition, and bug fix must be staged and committed atomically using Conventional Commits syntax (`feat:`, `fix:`, `style:`, `docs:`, `refactor:`, `test:`, `chore:`) with realistic timestamp spacing.
- **Never lump multi-file features into single bulk commits.**
